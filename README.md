# 内装見積自動化ツール

このリポジトリには、Numbersで作成した内装見積テンプレート（CSVにエクスポートしたもの）、単価マスタCSV、現場メモ（JSON）を入力として、インボイス対応済みの見積PDFとメール下書きを自動生成するPythonスクリプトが含まれています。

## 特長

- テンプレートの品目情報と単価マスタを突合し、不足する単価を自動補完。
- 現場メモに記載した調整項目や特記事項を見積に反映。
- 税別合計は四捨五入、税込合計は切り上げに対応（税率は設定可能）。
- 適格請求書発行事業者登録番号をPDF・メールに明記。
- 生成後にメール下書き（To/Cc/件名/本文）を自動作成。
- リトライ設定により、ファイル読み込みなどで失敗した場合でも所定回数再試行。

## 前提

- Numbersの雛形はCSVとしてエクスポートしてください。列構成は `品名/単価/単位/数量/小計` を想定しています。
- 単価マスタCSVも `品名/単価/単位` というヘッダーを持つUTF-8 (BOM付き可) を想定しています。
- 現場メモはJSON形式で、`samples/projects/sample_a/memo.json` を参考に各種情報（宛先、適格請求書番号、調整項目、メール設定など）を定義してください。

## 使い方

### 1. サンプル案件での検証

サンプルデータ一式は `samples/` に格納しています。以下を実行すると3案件分のPDFとメール下書きが `outputs/sample_runs/` に生成されます。

```bash
python -m estimate_automation.cli samples/sample_projects.json
```

### 2. 本番運用

1. `config/production_template.json` をコピーし、実際のファイルパスと案件情報に差し替えます。
2. 単価マスタCSV・テンプレートCSV・現場メモJSONを用意します。
3. 以下のコマンドで本番案件を処理します。

```bash
python -m estimate_automation.cli path/to/your_config.json
```

必要に応じて `--project <name>` オプションを指定すると、特定案件のみを再実行できます。

## 出力内容

- `*_estimate.pdf`: 見積書PDF（簡易レイアウト）。
- `*_email.txt`: メール下書き。税込合計や適格請求書番号の記載を含みます。

## リトライ制御

設定ファイルの `retry.max_attempts` と `retry.delay_seconds` で制御します。例では最大3回・1秒間隔で再試行するよう設定しています。

## 免責

生成されるPDFは簡易的なテキストレイアウトです。正式な帳票が必要な場合は、デザイン調整や帳票ライブラリの導入を検討してください。
